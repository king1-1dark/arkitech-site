# Arkitech Studio — сайт

Тестовый лендинг студии разработки игр **Arkitech Studio** — [arkitech.studio](https://arkitech.studio).

Чистые HTML + CSS + JS, без сборки и зависимостей. Многослойный параллакс в стиле 2D-игр: слои двигаются с разной скоростью от скролла и (на ПК) за курсором.

## Запуск локально

Открыть `index.html` в браузере — или поднять локальный сервер:

```bash
node .claude/serve.js
```

и перейти на `http://localhost:8123`.

## Что где

- `index.html` — разметка и тексты
- `css/style.css` — стили (цвета и шрифты — в переменных `:root`)
- `js/config.js` — **ссылка на Telegram-бота** и пути к слоям параллакса
- `js/main.js` — параллакс, меню, анимации
- `assets/layers/` — слои параллакса (сейчас SVG-заглушки)
- `assets/img/` — обложки игр, превью для соцсетей

Подробная инструкция по правкам и замене графики — в [CLAUDE.md](CLAUDE.md).

## Перед запуском в прод

- [ ] Вписать имя бота в `js/config.js` (`BOT_URL`)
- [ ] Заменить тестовые тексты, контакты и ссылки на соцсети
- [ ] Заменить слои-заглушки и обложки игр своей графикой
- [ ] Настроить DNS домена и включить Enforce HTTPS в настройках GitHub Pages

## Публикация

GitHub Pages, ветка `main`, корень. Домен задан в файле `CNAME`.
